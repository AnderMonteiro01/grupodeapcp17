# FoodToGo - versão W2 simplificada por user stories

Fluxo principal:
- Visitante: vê restaurantes e menus; cria conta/inicia sessão.
- Cliente: adiciona produtos ao carrinho com JavaScript, altera quantidades, confirma encomenda e consulta últimas encomendas.
- Restaurante: gere os dados do restaurante associado, produtos/menu, disponibilidade e estados das encomendas.
- Admin: gere utilizadores, restaurantes e associação utilizador-restaurante.
